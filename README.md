PromptForge Agent

About the Project

PromptForge Agent is an AI-powered prompt optimization tool designed to improve prompts, reduce token usage, and generate effective instructions for AI models.

Features

- Agentic Prompt Optimizer
- AI-powered clarification questions
- Master Prompt Generation
- Eco Prompt (Token Optimization)
- Reverse Engineering of Text
- Image-to-Prompt Generation
- Voice Input Support
- Self-Correction using User Feedback

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Tailwind CSS
- Generative AI

Project Structure

PromptForge-Agent/
├── app.py
└── templates/
    └── index.html

How to Run

1. Install the required Python dependencies.
2. Configure your API key securely.
3. Run the Flask application.
4. Open the local URL in your browser.
